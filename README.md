# U-Tube Manometry Analysis in MATLAB

Code developed in **MATLAB** for processing experimental data obtained using a U-tube manometer.

## 📌 Description
The script performs the following calculations based on experimental measurements:
- Calculation of height differences ($\Delta h$).
- Determination of hydrostatic pressure ($P$).
- Calculation of the resulting pressure force ($F$).

## 🛠️ Requirements
- **MATLAB**
